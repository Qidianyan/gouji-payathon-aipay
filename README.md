# 作品说明（正式定稿版 v1.0）· Vibe Pay 主赛道
## 勾稽：真实中国电子发票多模态精识与三单勾稽，按张付费、未用秒退

### 1. 一句话价值主张
勾稽面向小微企业与代账机构，对真实中国电子发票（PDF 原件、票面图像与国税局二维码）执行多模态结构化提取、**发票—合同—资金流水三单勾稽**与**红字冲销差额计算**，一键生成借贷平衡记账凭证并导出金蝶/用友标准 CSV；接入支付宝 Vibe Pay 网页/H5 收款，支持 ¥0.99 破冰体验包与主力次数包，识别失败不扣次，未用完次数随时按比例原路退款。

- **真实边际成本实测**：经多模态视觉实测（长边压缩至 ≤1024 px），单张电子发票视觉识别输入约 790–855 tokens、输出约 75 tokens，单次模型可变成本约 **¥0.0023–¥0.0036/张**（叠加支付宝 0.6% 通道费后单次总变动成本 < ¥0.01），全线套餐毛利率稳定在 **85% 以上**。

### 3. 核心业务与支付闭环链路（本地可复现：`http://127.0.0.1:8703`）
1. **双通道真票识别（零假桩）**：
   - **PDF 原件确定性解析**：通过 `pypdf` 提取电子发票版式文本层与国家税务总局二维码（`01,10/01/32/51,...`），毫秒级提取发票代码/20 位数电票号、开票日期、购销方 18 位统一社会信用代码、不含税金额、税率与税额；
   - **图像多模态精识**：支持上传 PNG/JPG 发票照片，自动将长边等比缩放至 ≤1024 px，优先调用内网 `CLIProxyAPI`（`gemini-4-carbon-high`），无内网时自动无缝切换标准 OpenAI 多模态接口与二维码/版式兜底，带超时指数退避重试；**若票据文件损坏无法解析，返回 422 且严格不扣减额度**。
2. **三单勾稽与红冲差额引擎**：
   - 自动核验：**票面价税数学勾稽**（`不含税 + 税额 == 价税合计`）、**购买方 18 位税号规范与账套匹配**、**票同勾稽**（销方名称、税率、开票期、票同差额）、**票款勾稽**（流水实付差额自动拆分 `银行存款` / `应付账款` / `预付账款`）；
   - **红字冲销差额精确反算**：当票面超出合同总额、发生销售折让退回或直接上传负数红字发票时，按税法公式精确到分反算应冲减不含税金额与进项税额转出，确保 `红冲不含税 + 红冲税额 == 红冲价税合计` 且全凭证借贷恒平，一键导出金蝶云星辰/用友好会计标准 CSV。
3. **金融级收款、补单与按比例退款冲正**：
   - 下单支持 `alipay.trade.page.pay`（跳转链接与自动提交 POST 表单双模式）及 `alipay.trade.wap.pay`；
   - **只认已验签异步通知或主动查询**：`/alipay/notify` 严格校验 `app_id`、`seller_id`、`total_amount` 与 `rsaCheckV1` 签名，按 `out_trade_no:trade_status` 幂等入账；同步 `return_url` 仅作状态轮询展示，绝不直接入账；
   - **主动补单与关单**：异步通知因网络抖动未达时，`GET /billing/orders/{id}` 自动调用 `alipay.trade.query` 补单；超时未付自动关单；
   - **按比例原路退款**：按 `实付分 × 剩余次数 // 总次数` 向下取整到分，调用 `alipay.trade.refund`（支持 `fastpay.refund.query` 核验）原路退回并原子冲正 SQLite 账本，全程追加写入 SHA-256 哈希审计链。
